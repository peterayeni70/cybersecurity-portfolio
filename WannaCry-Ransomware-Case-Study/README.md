## Project Overview
This project examines the WannaCry ransomware attack of May 2017, one of the largest and most disruptive cyberattacks in history. The research focuses on the technical origins of the malware, its rapid global spread, the vulnerabilities it exploited, and the lessons organizations can learn to strengthen their cybersecurity posture.

## Project Objectives
- Research the technical origins of WannaCry.
- Analyze the EternalBlue exploit used by the attackers.
- Document the timeline of the attack and its global impact.
- Examine response efforts from organizations and the cybersecurity community.
- Identify vulnerabilities that enabled the attack.
- Develop strategic security recommendations.

## Key Topics Covered
**Technical Origins**
- WannaCry Ransomware

- SMBv1 Vulnerability
- Microsoft Security Bulletin MS17-010

**Attack Timeline**
- Initial outbreak
- Global propagation
- Impact on healthcare, government, and businesses
- Discovery of the kill switch
- Recovery and remediation efforts

**Impact Analysis**
- Operational disruption
- Financial losses
- Healthcare service interruptions
- Critical infrastructure risks

**Response Efforts**
- Microsoft emergency patch releases
- Incident response activities
- International cybersecurity collaboration
- Security awareness initiatives

## Key Lessons Learned
- Patch management is critical.
- Legacy systems introduce significant risk.
- Network segmentation reduces attack spread.
- Regular backups improve ransomware resilience.
- Security awareness is essential for all organizations.
