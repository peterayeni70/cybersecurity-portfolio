## Project Overview

This project evaluates personal cybersecurity practices to identify potential vulnerabilities, assess current security controls, and develop a structured improvement plan. The audit focuses on cyber hygiene, including password management, device security, online behavior, privacy settings, and data protection practices.

## Project Objectives
- Evaluate current cybersecurity habits and practices.
- Identify personal security risks and vulnerabilities.
- Compare existing practices against cybersecurity best practices.
- Develop a prioritized remediation plan.
- Improve awareness of modern cyber threats.

## Areas Assessed

**Password Security**
- Password complexity
- Password uniqueness
- Password reuse
- Password manager usage
- Multi-Factor Authentication (MFA)

**Device Security**
- Operating system updates
- Antivirus protection
- Device encryption
- Biometric authentication
- Screen lock configuration

**Online Behavior**
- Social media privacy settings
- Public profile exposure
- Interaction with unknown users
- Link verification habits

**Data Protection**
- Backup routines
- Cloud storage security
- MFA implementation
- Recovery preparedness

## Key Vulnerabilities Identified
- Public social media exposure
- Inconsistent backup practices
- Lack of password manager usage
- Potential data exposure risks
- Limited privacy controls

## Risk Assessment
The audit classified identified vulnerabilities based on:
- High Risk
- Medium Risk
- Low Risk
to prioritize remediation efforts.

## Skills Demonstrated
- Security Auditing
- Risk Assessment
- Vulnerability Identification
- Security Awareness
- Cyber Hygiene Evaluation
- Security Documentation

## Outcome
The audit provided a comprehensive assessment of personal cybersecurity posture and produced a structured action plan to reduce risk and improve overall digital security.
