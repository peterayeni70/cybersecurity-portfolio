## Project Overview
This project analyzes the SolarWinds supply chain attack, one of the most significant cybersecurity incidents in history.

## Objectives
- Analyze the attack timeline
- Identify root causes
- Examine security failures
- Document lessons learned

## Key Topics
- SUNBURST Malware
- Supply Chain Security
- Incident Response
- Zero Trust Security

## Skills Demonstrated
- Incident Analysis
- Threat Research
